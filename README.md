Mekala Rushi Kumar • Premium 3D Portfolio Website
A highly interactive, single-page 3D developer portfolio website built using the Antigravity UI & Motion Design philosophy. The site features a luxury Electric Amber & Obsidian Black color palette, smooth transitions, spatial particle physics, and 3D card tilt transformations.

🌟 Key Features
Obsidian & Amber Visual Theme: Sleek dark matte backdrop (#050505) with bright warm amber (#ff8c00) and gold (#ffb900) glows.
Three.js Spatial Background: A 3D WebGL particle field that drifts dynamically in response to mouse movements.
3D Card Tilt Interaction: Technical skills and project panels tilt dynamically on hover in 3D space (perspective and preserve-3d).
GSAP Staggered Animations: Smooth, physics-based slide-ups and staggered card reveals as the page loads and user scrolls.
Streamlined Loader: Multi-language greetings ("HELLØ" → "NAMASTHE" → "WELCOME") that fade out and reveal the main surface smoothly without delay.
Responsive Layout: Fully optimized for all viewports—from 4K screens down to mobile devices.
🛠️ Technology Stack
Structure: HTML5 (Semantic tags)
Styling: CSS3 (Custom 3D transforms, glassmorphic shadows, keyframe animations)
Logic & WebGL Background: Vanilla JavaScript + Three.js (via CDN)
Animations: GSAP (GreenSock) + ScrollTrigger (via CDN)
Icons: Lucide Icons (via CDN)

⚡ Setup & Local Development
No compilation or complex packaging pipelines are required. You can serve the static files locally:

1. Using Python (Recommended)
Open your terminal inside the project directory and run:

bash

python -m http.server 8000
Then open your browser and navigate to: http://localhost:8000

2. Using Node.js / npm
Install http-server globally and run:

bash

npm install -g http-server
http-server -p 8000
Then navigate to: http://localhost:8000
